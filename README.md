# CYCLE+

Plateforme de révision scolaire pour le Cycle d'orientation genevois.

## Fonctionnalités de la première version
- Sélection du niveau (9e, 10e, 11e) et du regroupement / de la section.
- Matières : mathématiques, anglais, allemand, physique, biologie et latin.
- Cours avec explications, exemples et points à retenir.
- Exercices avec choix du nombre de questions, correction et explications.
- Flashcards de vocabulaire avec cartes à revoir.
- Évaluations chronométrées de 15, 20 ou 45 minutes.
- Calcul de moyenne pondérée.
- Sauvegarde locale de quelques éléments de progression via le navigateur.

## Lancer le site
Le projet est un site statique : ouvrir `index.html` dans un navigateur ou publier le dépôt avec GitHub Pages.

## Publication GitHub Pages
Dans le dépôt, ouvrir **Settings → Pages**, choisir **Deploy from a branch**, sélectionner **main** et le dossier **/(root)**, puis enregistrer.

## À propos des contenus
Cette première version contient une structure fonctionnelle et des exemples de cours, de questions et de vocabulaire. Elle ne représente pas encore l'intégralité du programme officiel genevois ni toutes les listes de vocabulaire de chaque année, regroupement et section. Les contenus doivent être développés et vérifiés progressivement à partir des objectifs et supports de cours de l'établissement.

## Technologies
HTML, CSS et JavaScript natifs. Aucune installation nécessaire.
